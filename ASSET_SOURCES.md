# Game Asset Sources & License Policy

The portal follows a commercial-safe asset policy: prefer assets with an explicit CC0/public-domain license and keep source/license records with the project.

## Approved source: Kenney
Kenney states that game assets on its asset pages are public-domain CC0 and may be used in commercial projects; attribution is not required. The Kenney logo itself is reserved for official Kenney projects.

Official source pages used as the approved art direction/source catalog:
- https://kenney.nl/assets/platformer-characters
- https://kenney.nl/assets/new-platformer-pack
- https://kenney.nl/assets/platformer-art-pixel
- https://kenney.nl/assets/space-shooter-remastered
- https://kenney.nl/assets/racing-pack
- https://kenney.nl/assets/top-down-shooter
- https://kenney.nl/assets/shooting-gallery
- https://kenney.nl/assets/pirate-pack

License policy: re-check the live asset page and included License.txt before publishing any newly downloaded third-party asset. Do not copy trademarks, logos, or copyrighted game characters from unrelated games.

## Current build
The current games build keeps its bundled local artwork self-contained so the games do not depend on remote image hotlinks at runtime. The visual system is designed so CC0 character/environment packs can be swapped into the same engine without changing gameplay code.
